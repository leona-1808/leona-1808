<summary><b>🚑 ResQRoute — AI-Powered Ambulance Routing System</b></summary>
<br/>

Full-stack ML system that predicts **real-time road travel time** and dynamically routes ambulances to the **fastest-reachable hospital** using Dijkstra's algorithm run over predicted, not static, travel times.

| Metric | Detail |
|---|---|
| **Stack** | Python, Flask, Scikit-learn, SQLAlchemy, Leaflet.js |
| **Scale** | Real-time routing across a live traffic-data road network |
| **Performance** | Random Forest / Decision Tree / Linear Regression compared — R² of 0.73 |
| **Security** | REST API with structured request validation |
| **Impact** | Cuts emergency response routing to a data-driven, live-updating decision |
| **Repository** | [GitHub](https://github.com/leona-1808/ResQRoute) · [Live Demo](https://resqroute-g1wa.onrender.com/) |

An interactive **Leaflet.js dashboard** visualizes predicted routes in real time, turning a traditionally static shortest-path problem into a continuously re-optimized one driven by live model predictions.
